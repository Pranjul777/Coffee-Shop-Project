# Coffee-Shop-Project
Dashboard.pdf
Description:

This project focuses on analyzing and visualizing sales performance data from a fictional coffee shop using Microsoft Excel. The dataset includes daily transactional records of items sold, sales amount, customer categories, and payment methods.

* *Data Cleaning & Preparation:*

  * Removed duplicates and null values.
  * Standardized product categories (e.g., Coffee, Pastries, Sandwiches).
  * Created structured tables for analysis.

* *Sales Dashboard:*

  * Built an interactive dashboard using *PivotTables, **Slicers, and **PivotCharts*.
  * Visualized *total revenue, **average sales per day, **best-selling products, and **sales by payment type*.
  * Included *month-over-month sales trends*.

* *KPIs Calculated:*

  * Total sales revenue
  * Daily and monthly sales trends
  * Top 5 selling items
  * Peak sales hours
  * Customer purchase patterns

* *Advanced Excel Techniques Used:*

  * *VLOOKUP, **IF, **COUNTIF, **SUMIFS* functions
  * *Data validation* and *conditional formatting* for quality checks
  * *Dynamic charts* and *drop-down filters* for user interactivity

*Outcome:*
Helped uncover insights like peak business hours, high-demand menu items, and customer preferences—allowing for better decision-making related to staffing, inventory, and marketing..
